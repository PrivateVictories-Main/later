# Security

## Reporting a vulnerability

Please report security problems **privately**, using GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for a security problem.

Include what you found, how to reproduce it, and the macOS and Later versions. You will get a reply as soon as it can be read; there is no fixed response time, since this is a one-person project.

## What matters most

Later's promise is that your data stays on your Mac. These are the kinds of problems that count:

- anything that makes Later send data off the Mac, or that adds a network entitlement or network code;
- reading more than [PRIVACY.md](PRIVACY.md) says (for example, private-window tabs);
- saving links that carry tokens, passwords or other secrets;
- a way for another app or web page to read or change Later's saved list.

## Supported versions

Only the latest release gets fixes.
